## 事故与修复：场景 UI 文案全部消失（16 个 Text 组件被重置）

用户反馈「场景里面的文本不见了」。定位结果**是我 9-18 那次中文化的锅**，已修复。

### 根因链（已用备份逐组件比对确认）

1. 9-18 的 `rope_scene_patch.py` 用正则把旧版 UI Text 的 `m_Font` 换成 DroidSansFallback 时
   **丢了缩进**，写成缩进 0（正确应在 `m_FontData:` 下缩进 4）：
   `CoinShop.unity` 还能看到现场（11 处 `m_Font`，其中 6 处缩进 0）。
2. Unity 读到缩进坏的 YAML → **反序列化失败 → 整个 Text 组件回默认值**：
   `m_Text:` 空、`m_Font: {fileID: 0}`、`m_FontSize: 14`、`m_Alignment: 0`。
   中文化的 16 条文案在这一步就丢了。
3. 13:09:45 编辑器保存场景（内存里已是默认值）→ 损坏落盘。
4. 铁证：**凡是我改过的 16 个 Text 全废，没改过的 4 个（`00`/`+1500`/`-150`/`0`）完好无损**。

### 修复方案（改走 Editor 脚本，不再碰 YAML）

新增 `Assets/MyAssets/Editor/RopeUITextRestore.cs`（UTF-8 BOM）：

- 用 `_RopeScene_Backup_20260919_110241\Gameplay.unity` 重建每个组件的
  **fileID + 层级路径 + 字号/样式/对齐/最大字号**，双键匹配：
  `GlobalObjectId.GetGlobalObjectIdSlow(t).targetObjectId` + `PathOf(transform)`。
- 16 条文案按中文化方案写回（点击开始/商店/抽奖/下一关/重试/关闭/恭喜中奖/关卡完成/关卡失败/
  主页/跳过关卡/更多关卡 敬请期待/第 00 关/抽奖 -100/可以抽奖啦！…），字体统一 DroidSansFallback。
- 触发：`[InitializeOnLoadMethod]` + `EditorApplication.delayCall` 切回 Unity 自动修一次；
  另有菜单 `Tools/打个毛线/修复场景文本（中文化）`、`Tools/打个毛线/检查场景文本状态`。
- 幂等：只在 `font == null || text 为空` 时才动；表里没有的只补字体不动文案。
- 用户**没打开**的场景用 `OpenScene(Additive)` → 修 → 存 → `CloseScene`，不打扰当前编辑。

另外直接修了 `CoinShop.unity` 里 6 行缩进错误的 `m_Font`（写回缩进 4），
备份 `_RopeSceneBackup2_20260919_134234\CoinShop.unity`。全工程扫过，**没有别的同类残留**。
