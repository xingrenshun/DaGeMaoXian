## 排查「无法切换精灵图」（用户截图 `Assets/AdSDK/Resources/按钮.png`）

### 结论（根因）
- `按钮.png` / `位图备份 2.png` / `ima1.png` 被设成了 **`spriteMode: 2`（Sprite Mode = Multiple）**，
  但 `spriteSheet.sprites: []` —— **一张都没切**。
- 后果：**这张贴图不生成任何 Sprite**（Multiple 模式的精灵是子资产），所以
  `Image.Source Image` 里选不到、`Resources.Load<Sprite>` 拿不到 → 用户看到的「无法切换精灵图」。
- 单张图必须 `spriteMode: 1`（Single）。Multiple 模式下 sprite 的 fileID 是哈希值，
  原 `{fileID: 21300000, guid: …}` 的引用会全部断裂。
- 三个文件的 meta 都在 **9-19 15:35** 被重写（15:35:14 两个 + 15:35:49 一个）——全工程那段时间
  只有这 3 个文件被改，典型是**在 Project 里多选后一起点 Apply**，Sprite Mode 被连带改成 Multiple。
  （我 9-19 11:09 的贴图瘦身脚本没碰过这 3 个：备份目录里没有它们的 meta。）

### 关于截图底部那条警告
`Only textures with width/height being multiple of 4 can be compressed to DXT5/BC3 format`
—— 这是**压缩格式**的警告，跟精灵能不能用无关：宽或高不是 4 的倍数时，Unity 无法用 DXT5/BC3，
会静默退回未压缩格式（只影响包体）。
- `按钮.png` 217×75 → 两个维度都不是 4 的倍数
- `ima1.png` 330×118 → 都不是
- `位图备份 2.png` 64×64 → 是 4 的倍数（无此警告）
- `领取按钮.png` 952×211 → 高不是
修法是把 PNG 补边到 4 的倍数（这几张图都很小，收益 <100KB，**没做**）。

   **但另外两个 6 秒后被 Unity 写回**（19:29:09）→ 证明**编辑器开着时外部改 `.meta` 会被内存版本覆盖**。

   - `[InitializeOnLoad]` + `EditorPrefs` DoneKey 自动跑一次，另有菜单
     `Tools/打个毛线/修复精灵模式（Multiple→Single）` 和 `检查精灵模式状态`；
   - 每步 try/catch，单个失败不影响其它；API 与括号配平已核对通过。
3. 备份：`…\_RopeSpriteFix_Backup_20260920_192903\`（3 个 .meta 原件）。
