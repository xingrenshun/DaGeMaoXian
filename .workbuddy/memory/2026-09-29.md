## 本次实测出的完整玩法事实（840 关全量统计，后续写短简介不必重探）

- **关卡**：840 个 JSON（`001-E` … `840-N`），`levelsJson` 索引 0–839 ↔ `levelNo < 839` 判末关。
- **台面尺寸**：22 种，2×3 起步 → 最大 8×8；6×6(354)/7×7(179)/7×6(132) 为主。
- **线轴数**：最少 6、最多 64、平均 41.4。
- **每关配色种数**：2 → 11；10 色关占 663、9 色 136、11 色 9。
- **收纳槽数量**（`LevelSpawner.SpawnRollContainers`）：**<4 关=4 个，4–11 关=5 个，12–23 关=6 个，≥24 关=7 个**。
- **可点规则**（`RollMovableManager.IsRollPathBlocked`）：上下左右任一格为空 **或出界** 即可点；
  被 `Roll_` / `Obstacle_` / `Pipe_` 占住即视为堵死。点击总闸在 `Roll.OnMouseDown`：
  `if (!isMovable || isFrozen || lockObj || !gameManager.gameStarted) return;`
- **消除**：`Roll.cs:221` `ropeCount / 72` → **缠满 72 圈**整束消失、槽位重空。
- **失败**（`RollsManager.CheckRetryInvoke`）：所有 `RollContainer` 都非空，且没有任何一列队列前端颜色能与槽内线轴匹配 → `gameManager.Retry()`。
- **关卡 JSON 字段**（`LevelData.cs`）：`gridSize.x/y`、`totalBlock`、`blocks[].{position,type,linkType,state{isHidden,isFrozen,isLocked,isKey,groupID,color},targetDirection,attachments[]}`、`blindQueues[]`。
- **机关出现次数**（840 关累计）：遮布 `isHidden` **2397**（最多）、冰块 `isFrozen` 334、锁 84 / 钥匙 70、
  成对连环 `linkType==1` **644**、带挂件方块 1924、`Obstacle_` 固定障碍、`Pipe_` 管道。
  - 遮布：`LevelSpawner` 挂 `hideModelObj`，**`Roll.CanMove()` 里 `hideModelObj.SetActive(false)`** → 该线轴变得可动时遮盖自动揭开。
  - 冰块：`frozenObj` 下有 **多层** `frozenObjects`，`Unfreeze()` 逐层 `Destroy`，`freezeCount==0` 才解除。
  - 上队列 `BlindQueueColumn` 也有 `isHidden` 项；队列列数：4 列 820 关、3 列 15 关、5 列 5 关。
- **系统**：金币（`PlayerPrefs "CoinsAmount"`，初始 100）；每日免费转盘 24h 且 **真发金币**
  （`SpinWheelTimer` → `CoinsManager.AddCoins(wheelPiece.Amount)`）；跳关消耗 **`skipLevelCoinAmount: 150`**（写在 `Gameplay.unity`）；
  金币商店实为**看广告换币**（`IAPShopManager.PurchaseComplete(coins)` → `AdsManager.ShowRewardedAdForCoins`）；
  音效 17 处（Click/RollSpawn/RollMove/RollMoved/RollDestroy/IceBreak/Unlock/Key/Buy/Retry/Win/Reward/Toast/Coins）。
- **无**角色、无 NPC、无剧情、无倒计时。竖屏单指点击。
