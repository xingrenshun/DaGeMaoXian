### 一、包体瘦身（本次主攻，已完成主体）

**先做体积精算**（脚本 `%TEMP%\rope_build_estimate.py` / `rope_est2.py` / `rope_final_report.py`）：
- 排除 `.meta`（0.57MB，不进包）与 `/Editor/`、GoogleMobileAds、MobileDependencyResolver 后，
  **进包资源 ≈ 50.07MB**。
- 结论：**纹理是绝对大头**（导入像素 27.42 MPix ≈ DXT5 26.15MB，含编辑器专用后 21.83MB 会进包），
  其次关卡 JSON 12.81MB、字体 3.65MB、音频 2.23MB。
- 关键坑：算纹理体积必须**先按 `maxTextureSize` 收敛再算像素**。`WinEmoji.png` 源 3584x5120、
  `512 (1).png` 3584x4608 看着吓人，但 meta 里 maxTextureSize=2048，实际导入只有 1433x2048 / 1592x2048。
  直接拿源尺寸算会高估 5 倍。

**已执行改动**（均有备份）：

1. **纹理 .meta 批处理**（`%TEMP%\rope_meta_opt.py --apply`，82 个文件）
   - `enableMipMap 1→0`、`maxTextureSize → 1024`、`crunchedCompression 0→1`
   - 背景类（名字含 bg/background/GameBg）例外保留 2048，只开 Crunch，防整屏发糊
   - **Multiple 雪碧图（spriteMode: 2）也一起降尺寸是安全的** —— Unity 会按比例同步缩放子图 rect
   - 结果：21.83MB → 13.09MB（省 8.74MB）
2. **音频 .meta**：`compressionFormat→Vorbis(1)`、`quality→0.3`（BGM 0.35）、
   ≥1MB 走 `CompressedInMemory(1)`、小音效 `forceToMono: 1`
   - 结果：2.23MB → 0.33MB（省 1.90MB）
3. **字体子集化**（`%TEMP%\rope_font_subset.py`）
   - `AdSDK/Font/DroidSansFallback.ttf` 3115KB → **1110KB**（保留 GB2312 全字库 7445 + 工程用字 617 + ASCII/符号）
   - `MyAssets/Font/NEXON Football Gothic B.otf` 628KB → **16KB**
   - 省 2.56MB
   - 原理：该字体在 meta 里 `includeFontData: 1` + `forceTextureCase: -2`(Dynamic)，
     即 **TTF 原文件整份进包**，所以子集化文件 = 直接减包体，1:1。
   - 安全网：不只收工程用字，而是**并上 GB2312 全部 7445 码位**，覆盖简体 99.9%+，
     避免以后改文案出现白块。校验过关键文案全命中。
4. **删掉运行时日志**：`LevelSpawner.cs` 里每关都 `Debug.Log($"JSON Content: {jsonContent}")`，
   单关 JSON 中位 15.6KB，真机必卡。已用 `#if UNITY_EDITOR` 包住。

**总账：27.72MB → 14.52MB（省 13.20MB / 48%）；预估上架包体 ≈ 23MB。**
